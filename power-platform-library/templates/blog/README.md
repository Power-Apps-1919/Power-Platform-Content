# Article title

Write the article content here. Put article images in this folder's `images` directory.

## Downloadable resources

Put files that readers should download in a `downloads` directory beside this README.
This can contain Power Platform solution ZIP files, apps, PDFs, JSON, or other
supporting resources:

```text
your-article/
  README.md
  images/
  downloads/
    solution.zip
```

Link a file from the article with a relative Markdown link:

```md
[Download the solution](./downloads/solution.zip)
```

The build copies the file to the published downloads area and preserves nested
folders. Do not place secrets, environment-specific connection credentials, or
production data in downloadable files.
