## Component documentation

## Business value
Make category comparisons readable when labels are long or when users need to rank items, teams, or work queues.

## Best for
- Department or regional rankings.
- Long category names.
- Operational dashboards where the order of items drives action.

## What to provide
- `Items`: labels and values.
- `Config`: layout, title, KPI, axes, colours, and spacing.

## Getting started
Use `cmp-horizontal-bar-chart.yml` as a reference while creating or maintaining the equivalent component in a component library or approved source workflow; connect it to business data, sort the values intentionally, and confirm that labels remain readable on mobile and tablet screens.

## Using the component YAML safely

This download is a complete `ComponentDefinitions` source file. It is useful as a
versioned reference and for supported source-code workflows, but it should not be
treated as an ordinary control snippet.

### Recommended reusable approach: component library

For a component that will be used across apps, Microsoft recommends a Power Apps
component library:

1. Open [Power Apps](https://make.powerapps.com).
2. Open **Component libraries** from **More** or **Discover all**, then create or
   open a library.
3. Create or maintain the component in the library and test it on a library screen.
4. Save the library, add version notes, and select **Publish**.
5. In the Canvas App, select **Insert** or **+**, choose **Get more components**,
   and select the shared library.
6. Add the component and configure its input, output, action, or event properties.

Published library versions can be updated and reviewed by apps that use them. This
is the best option when several makers or apps need the same component.

### Use a component in an individual app

For reuse only within one app, you can create an app-local component in Power Apps
Studio:

1. Open the app and select **Tree view**.
2. Select the **Components** tab, then **New component**.
3. Add the controls and custom properties that define the component.
4. On a screen, use **Insert** → **Components** to add an instance.

App-local components can be reused on multiple screens in that app. Changes remain
within that app; they do not provide the cross-app versioning and update
notifications of a component library.

### Copy and paste supported control YAML

Power Apps Studio also has **View code** for an individual control. Microsoft
documents this workflow for YAML generated by Studio:

1. Open the Canvas App for editing.
2. In the tree view or on the canvas, right-click an individual control and select
   **View code**.
3. Select **Copy code**, or use `Ctrl+C`.
4. In the destination app, select a screen or suitable location in the tree view.
5. Use **Paste** or `Ctrl+V` to create the control. This can be another screen in
   the same app or a different canvas app.
6. Approve browser clipboard access if Power Apps asks for it.

Studio validates the pasted code. This workflow applies to YAML that Power Apps
generated for a selected control and its child controls. It does not mean that a
full `ComponentDefinitions` file can be pasted into any code-view window.

### Can this complete file be pasted directly?

Do not assume that copying the entire downloaded file and pasting it into Code view
will create this component. These files define a Canvas component and its
properties, while Code view is documented for selected controls. If Studio rejects
the paste, that is expected for an unsupported format or location.

Use the component-library workflow for shared components. The older feature for
importing and exporting components between canvas apps is retired and disabled by
default; Microsoft documents a temporary per-app exception under **Settings** →
**Upcoming features** → **Retired** where that option is still available. Prefer
component libraries instead. If your organisation uses a supported source-code,
unpacking, or ALM process, keep this YAML in source control and follow that process
to apply it.

## Best practices

- Test first in a development environment with sample data.
- Keep the component interface small and use clear property names and descriptions.
- Pass business data through documented input properties rather than hard-coding records.
- Use output, action, and event properties only when the host app needs them.
- Confirm connector permissions, licensing, accessibility, responsive layout, and colour contrast.
- Save component-library versions with meaningful notes and publish changes deliberately.
- Validate formulas and data schemas after every update.
- Do not place secrets, connection credentials, personal data, or production exports in source files or downloads.

ComponentDefinitions:
  cmp_HorizontalBarChart:
    DefinitionType: CanvasComponent
    AllowCustomization: true
    CustomProperties:
      Config:
        PropertyKind: Input
        DisplayName: Config
        Description: 'Layout + behavior config record '
        RaiseOnReset: true
        DataType: Record
        Default: |-
          ={
            Size:{ Width:700 },

            Padding:{ L:120, R:30, T:18 },

            Title:{ Text:"Horizontal bar chart", H:26, Gap:12 },

            KPI:{
              Value:Blank(),
              SubText:"Total",
              H:56,
              Gap:18,
              W:180,
              Rx:10,
              PadX:12
            },

            Plot:{
              H:220,
              RowGap:10,
              AxisPadL:10,
              AxisPadR:10,
              BarRx:6
            },

            Grid:{ Lines:5 },

            Legend:{
              PadTop:40,
              PadBottom:10,
              Box:12,
              BoxGap:8,
              Gap:40,
              CharPx:7,
              RowH:20,
              Margin:20
            }
          }
      Items:
        PropertyKind: Input
        DisplayName: Items
        Description: 'Table. lbl, val, col '
        RaiseOnReset: true
        DataType: Table
        Default: |-
          =[
            { lbl: "Jan", val: 120, col: "#0D47A1" },
            { lbl: "Feb", val: 80,  col: "#1B5E20" },
            { lbl: "Mar", val: 150, col: "#B71C1C" },
            { lbl: "Apr", val: 60,  col: "#616161" }
          ]
      Theme:
        PropertyKind: Input
        DisplayName: Theme
        Description: 'Theme record '
        RaiseOnReset: true
        DataType: Record
        Default: |-
          ={
            Colors:{
              Background:"#FFFFFF",
              Title:"#222222",
              Grid:"#E6E6E6",
              Label:"#333333",
              ValueBg:"#F2F2F2",

              KpiFill:"#F6F6F6",
              KpiStroke:"#DADADA",
              KpiSub:"#666666",
              KpiText:"#111111",

              LegendText:"#111111"
            },
            Font:{
              Family:"Segoe UI",

              TitleSize:14,
              TitleWeight:"600",

              LabelSize:13,
              LabelWeight:"600",

              ValueSize:12,
              ValueWeight:"700",

              LegendSize:12,
              LegendWeight:"600",

              KpiSubSize:12,
              KpiTextSize:18,
              KpiTextWeight:"700"
            }
          }
      fnModel:
        PropertyKind: OutputFunction
        DisplayName: Model
        Description: 'Returns base data + computed layout '
        DataType: Record
    Properties:
      fnModel: |-
        =With(
          { it: Self.Items, t: Self.Theme, cfg: Self.Config },
          With(
            {
              // ---- config resolved ----
              w: Coalesce(cfg.Size.Width, 700),

              padL: Coalesce(cfg.Padding.L, 120),
              padR: Coalesce(cfg.Padding.R, 30),
              padT: Coalesce(cfg.Padding.T, 18),

              titleText: Coalesce(cfg.Title.Text, "Horizontal bar chart"),
              titleH: Coalesce(cfg.Title.H, 26),
              titleGap: Coalesce(cfg.Title.Gap, 12),

              kpiVal: cfg.KPI.Value,
              kpiSub: Coalesce(cfg.KPI.SubText, ""),
              kpiH: Coalesce(cfg.KPI.H, 56),
              kpiGap: Coalesce(cfg.KPI.Gap, 18),
              kpiW: Coalesce(cfg.KPI.W, 180),
              kpiRx: Coalesce(cfg.KPI.Rx, 10),
              kpiPadX: Coalesce(cfg.KPI.PadX, 12),

              plotH: Coalesce(cfg.Plot.H, 220),
              rowGap: Coalesce(cfg.Plot.RowGap, 10),
              axisPadL: Coalesce(cfg.Plot.AxisPadL, 10),
              axisPadR: Coalesce(cfg.Plot.AxisPadR, 10),
              barRx: Coalesce(cfg.Plot.BarRx, 6),

              gridLines: Coalesce(cfg.Grid.Lines, 5),

              // legend
              legPadTop: Coalesce(cfg.Legend.PadTop, 40),
              legPadBottom: Coalesce(cfg.Legend.PadBottom, 10),
              box: Coalesce(cfg.Legend.Box, 12),
              boxGap: Coalesce(cfg.Legend.BoxGap, 8),
              gap: Coalesce(cfg.Legend.Gap, 40),
              charPx: Coalesce(cfg.Legend.CharPx, 7),
              rowH: Coalesce(cfg.Legend.RowH, 20),
              legendMargin: Coalesce(cfg.Legend.Margin, 20),

              // ---- theme resolved ----
              cBg: Coalesce(t.Colors.Background, "#FFFFFF"),
              cTitle: Coalesce(t.Colors.Title, "#222222"),
              cGrid: Coalesce(t.Colors.Grid, "#E6E6E6"),
              cLabel: Coalesce(t.Colors.Label, "#333333"),
              cValBg: Coalesce(t.Colors.ValueBg, "#F2F2F2"),

              cKpiFill: Coalesce(t.Colors.KpiFill, "#F6F6F6"),
              cKpiStroke: Coalesce(t.Colors.KpiStroke, "#DADADA"),
              cKpiSub: Coalesce(t.Colors.KpiSub, "#666666"),
              cKpiText: Coalesce(t.Colors.KpiText, "#111111"),

              cLegend: Coalesce(t.Colors.LegendText, "#111111"),

              fontFam: Coalesce(t.Font.Family, "Segoe UI"),

              fsTitle: Coalesce(t.Font.TitleSize, 14),
              fwTitle: Coalesce(t.Font.TitleWeight, "600"),

              fsLabel: Coalesce(t.Font.LabelSize, 13),
              fwLabel: Coalesce(t.Font.LabelWeight, "600"),

              fsVal: Coalesce(t.Font.ValueSize, 12),
              fwVal: Coalesce(t.Font.ValueWeight, "700"),

              fsLeg: Coalesce(t.Font.LegendSize, 12),
              fwLeg: Coalesce(t.Font.LegendWeight, "600"),

              fsKpiSub: Coalesce(t.Font.KpiSubSize, 12),
              fsKpiText: Coalesce(t.Font.KpiTextSize, 18),
              fwKpiText: Coalesce(t.Font.KpiTextWeight, "700"),

              // ---- normalize items ----
              base:
                ForAll(
                  Table(ParseJSON(JSON(it, JSONFormat.Compact))) As j,
                  {
                    lbl: Coalesce(Text(j.Value.lbl), ""),
                    val: Value(Coalesce(Text(j.Value.val), "0")),
                    col: Coalesce(Text(j.Value.col), "#616161")
                  }
                )
            },
            With(
              {
                n: CountRows(base),
                tot: Sum(base, val),
                maxV: Max(base, val),

                kpiOn: !IsBlank(kpiVal),
                kpiText: Text(Coalesce(kpiVal, Blank()), "[$-en-US]#,##0")
              },
              With(
                { avgLen: Sum(base, Len(lbl)) / Max(1, n) },
                With(
                  {
                    itemW: box + boxGap + (avgLen * charPx) + gap,
                    perRow: Max(1, RoundDown((w - legendMargin) / (box + boxGap + (avgLen * charPx) + gap), 0)),
                    legendRows: If(n > 0, RoundUp(n / Max(1, Max(1, RoundDown((w - legendMargin) / (box + boxGap + (avgLen * charPx) + gap), 0))), 0), 0)
                  },
                  With(
                    {
                      titleY: padT,
                      kpiY: padT + titleH + titleGap,

                      chartY: padT + titleH + titleGap + If(kpiOn, kpiH + kpiGap, 0),

                      plotX: padL,
                      plotW: w - padL - padR,

                      rowHPlot: If(n > 0, (plotH - rowGap * (n - 1)) / n, 0),

                      legendY:
                        padT + titleH + titleGap +
                        If(kpiOn, kpiH + kpiGap, 0) +
                        plotH + legPadTop,

                      h:
                        padT + titleH + titleGap +
                        If(kpiOn, kpiH + kpiGap, 0) +
                        plotH + legPadTop +
                        (legendRows * rowH) + legPadBottom
                    },
                    {
                      W:w, H:h,

                      PadL:padL, PadR:padR, PadT:padT,

                      TitleText:titleText, TitleY:titleY,

                      ChartY:chartY,
                      PlotX:plotX, PlotW:plotW, PlotH:plotH,
                      RowHPlot:rowHPlot, RowGap:rowGap,
                      AxisPadL:axisPadL, AxisPadR:axisPadR,
                      BarRx:barRx,

                      GridLines:gridLines,

                      LegendY:legendY,
                      RowH:rowH, Box:box, BoxGap:boxGap, Gap:gap, ItemW:itemW, PerRow:perRow,

                      N:n, Tot:tot, MaxV:maxV, Base:base,

                      Bg:cBg, Title:cTitle, Grid:cGrid, Label:cLabel, ValueBg:cValBg, LegendText:cLegend,

                      FontFam:fontFam,
                      FsTitle:fsTitle, FwTitle:fwTitle,
                      FsLabel:fsLabel, FwLabel:fwLabel,
                      FsVal:fsVal, FwVal:fwVal,
                      FsLeg:fsLeg, FwLeg:fwLeg,

                      KpiOn:kpiOn, KpiY:kpiY, KpiW:kpiW, KpiH:kpiH, KpiRx:kpiRx, KpiPadX:kpiPadX,
                      KpiFill:cKpiFill, KpiStroke:cKpiStroke, KpiSubClr:cKpiSub, KpiTextClr:cKpiText,
                      KpiSub:kpiSub, KpiText:kpiText,
                      FsKpiSub:fsKpiSub, FsKpiText:fsKpiText, FwKpiText:fwKpiText
                    }
                  )
                )
              )
            )
          )
        )
    Children:
      - img_HorizontalBarChartSvg:
          Control: Image@2.2.3
          Properties:
            Height: =Parent.Height
            Image: |
              =With(
                { M: Parent.fnModel() },
                With(
                  { B: M.Base, n: M.N },
                  "data:image/svg+xml;utf8," &
                  EncodeUrl(
                    $"
                    <svg xmlns='http://www.w3.org/2000/svg' width='{M.W}' height='{M.H}' viewBox='0 0 {M.W} {M.H}'>
                      <rect width='{M.W}' height='{M.H}' fill='{M.Bg}'/>

                      <!-- TITLE -->
                      <text x='{M.PadL}' y='{M.TitleY + 18}'
                            font-family='{M.FontFam}' font-size='{M.FsTitle}' font-weight='{M.FwTitle}' fill='{M.Title}'>
                        {M.TitleText}
                      </text>

                      <!-- KPI CARD (optional) -->
                      {
                        If(
                          M.KpiOn,
                          $"
                          <rect x='{M.PadL}' y='{M.KpiY}' width='{M.KpiW}' height='{M.KpiH}'
                              rx='{M.KpiRx}' ry='{M.KpiRx}' fill='{M.KpiFill}' stroke='{M.KpiStroke}'/>
                          <text x='{M.PadL + M.KpiPadX}' y='{M.KpiY + 22}'
                              font-family='{M.FontFam}' font-size='{M.FsKpiSub}' fill='{M.KpiSubClr}'>{M.KpiSub}</text>
                          <text x='{M.PadL + M.KpiPadX}' y='{M.KpiY + 44}'
                              font-family='{M.FontFam}' font-size='{M.FsKpiText}' font-weight='{M.FwKpiText}' fill='{M.KpiTextClr}'>{M.KpiText}</text>
                              ",
                          ""
                        )
                      }

                      <!-- GRIDLINES (vertical) -->
                      {
                        Concat(
                          Sequence(M.GridLines + 1) As g,
                          With(
                            { t: (g.Value - 1) / M.GridLines },
                            With(
                              { gx: M.PlotX + M.AxisPadL + (M.PlotW - M.AxisPadL - M.AxisPadR) * t },
                              $"
                              <line x1='{Text(gx,"[$-en-US]0.0")}' y1='{Text(M.ChartY,"[$-en-US]0.0")}'
                                  x2='{Text(gx,"[$-en-US]0.0")}' y2='{Text(M.ChartY + M.PlotH,"[$-en-US]0.0")}'
                                  stroke='{M.Grid}' stroke-width='1'/>"
                            )
                          )
                        )
                      }

                      <!-- BARS -->
                      {
                        Concat(
                          Sequence(n) As i,
                          With(
                            { r: Last(FirstN(B, i.Value)), idx: i.Value - 1 },
                            With(
                              { y: M.ChartY + idx * (M.RowHPlot + M.RowGap) },
                              With(
                                {
                                  bw: If(M.MaxV > 0, (r.val / M.MaxV) * (M.PlotW - M.AxisPadL - M.AxisPadR), 0),
                                  vTxt: Text(r.val, "[$-en-US]0.0")
                                },
                                $"
                                  <text x='{Text(M.PlotX - 10,"[$-en-US]0.0")}' y='{Text(y + (M.RowHPlot/2) + 5,"[$-en-US]0.0")}'
                                      font-family='{M.FontFam}' font-size='{M.FsLabel}' font-weight='{M.FwLabel}'
                                      fill='{M.Label}' text-anchor='end'>
                                  {Substitute(r.lbl, "&", "and")}
                                  </text>

                                  <rect x='{Text(M.PlotX + M.AxisPadL,"[$-en-US]0.0")}' y='{Text(y,"[$-en-US]0.0")}'
                                      width='{Text(bw,"[$-en-US]0.0")}' height='{Text(M.RowHPlot,"[$-en-US]0.0")}'
                                      rx='{M.BarRx}' ry='{M.BarRx}' fill='{r.col}'/>

                                  <rect x='{Text(M.PlotX + M.AxisPadL + bw + 8,"[$-en-US]0.0")}' y='{Text(y + (M.RowHPlot/2) - 9,"[$-en-US]0.0")}'
                                      width='{Len(vTxt) * 7 + 12}' height='18' rx='6' ry='6' fill='{M.ValueBg}'/>

                                  <text x='{Text(M.PlotX + M.AxisPadL + bw + 14,"[$-en-US]0.0")}' y='{Text(y + (M.RowHPlot/2) + 5,"[$-en-US]0.0")}'
                                      font-family='{M.FontFam}' font-size='{M.FsVal}' font-weight='{M.FwVal}'
                                      fill='{M.Label}' text-anchor='start'>
                                  {vTxt}
                                  </text>
                                "
                              )
                            )
                          )
                        )
                      }

                      <!-- LEGEND -->
                      {
                        Concat(
                          Sequence(n) As i,
                          With(
                            { r: Last(FirstN(B, i.Value)), idx: i.Value - 1 },
                            With(
                              { row: RoundDown(idx / M.PerRow, 0), colI: Mod(idx, M.PerRow) },
                              With(
                                { rowCnt: Min(M.PerRow, n - (row * M.PerRow)) },
                                With(
                                  { startX: (M.W - (rowCnt * M.ItemW - M.Gap)) / 2 },
                                  With(
                                    { lx: startX + (colI * M.ItemW), ly: M.LegendY + (row * M.RowH) },
                                    $"
                                      <rect x='{Text(lx,"[$-en-US]0.0")}' y='{Text(ly - 10,"[$-en-US]0.0")}' width='{M.Box}' height='{M.Box}' fill='{r.col}'/>
                                      <text x='{Text(lx + M.Box + M.BoxGap,"[$-en-US]0.0")}' y='{Text(ly,"[$-en-US]0.0")}'
                                          font-family='{M.FontFam}' font-size='{M.FsLeg}' font-weight='{M.FwLeg}' fill='{M.LegendText}'>
                                      {Substitute(r.lbl, "&", "and")}: {Text(r.val, "[$-en-US]0.0")}
                                      </text>
                                    "
                                  )
                                )
                              )
                            )
                          )
                        )
                      }
                    </svg>"
                  )
                )
              )
            Width: =Parent.Width
